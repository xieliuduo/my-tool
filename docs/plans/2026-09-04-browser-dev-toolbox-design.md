# 研发工具箱浏览器插件设计

## 目标

构建一个无需联网、可持续扩展的 Manifest V3 浏览器插件，将研发日常使用的小工具集中在一个紧凑的弹窗界面中。首版包含时间戳转换和时区转换。

## 方案

插件使用原生 HTML、CSS 和 ES Modules，不引入构建工具或第三方运行时依赖。这样可直接通过 Chrome 或 Edge 的“加载已解压扩展程序”安装，同时避免网络权限和供应链依赖。

弹窗顶部展示当前 Unix 时间戳，中部使用工具标签切换功能。日期时间的解析和格式化逻辑集中在 `src/utils/date-time.js`，UI 交互位于 `popup.js`。后续新增工具时，可以继续增加独立面板与工具模块。

时间戳转换通过数值大小自动判断秒或毫秒，输出北京时间、本地时间、UTC ISO、秒和毫秒。时间转换支持浏览器可解析的 RFC 2822、ISO 8601 等格式，并允许选择常见目标时区。所有计算均在本地执行。

## 错误处理与验证

空输入保持等待状态；非法时间戳和日期字符串显示明确错误，不产生错误结果。核心转换逻辑使用 Node.js 内置测试框架验证，重点覆盖秒/毫秒识别、GMT 到北京时间转换、ISO 输入和非法输入。
