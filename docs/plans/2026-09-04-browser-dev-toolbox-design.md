# 研发工具箱浏览器插件设计

## 目标

构建一个无需联网、可持续扩展的 Manifest V3 浏览器插件，将研发日常使用的小工具集中在独立的全窗口标签页中。当前包含时间戳转换、时区转换和文本数据对比。

## 方案

插件使用原生 HTML、CSS 和 ES Modules，不引入构建工具或第三方运行时依赖。这样可直接通过 Chrome 或 Edge 的“加载已解压扩展程序”安装，同时避免网络权限和供应链依赖。点击插件图标时，Manifest V3 Service Worker 创建独立的扩展标签页。

页面顶部展示当前 Unix 时间戳，中部使用工具标签切换功能，并通过 URL Hash 保留当前工具状态。日期时间的解析和格式化逻辑集中在 `src/utils/date-time.js`，UI 交互位于 `app.js`。后续新增工具时，可以继续增加独立面板与工具模块。

时间戳转换通过数值大小自动判断秒或毫秒，输出北京时间、本地时间、UTC ISO、秒和毫秒。时间转换支持浏览器可解析的 RFC 2822、ISO 8601 等格式，并允许选择常见目标时区。所有计算均在本地执行。

文本数据对比采用最长公共子序列完成行对齐，将结果并排展示为新增、删除、修改和未变化行。修改行继续比较公共前后缀，突出显示行内不同字符。工具同时提供 JSON 格式化、左右交换和清空操作，并限制单侧最多 1000 行以避免弹窗因超大输入失去响应。

## 错误处理与验证

空输入保持等待状态；非法时间戳、日期字符串和 JSON 显示明确错误，不产生错误结果。核心逻辑使用 Node.js 内置测试框架验证，重点覆盖秒/毫秒识别、GMT 到北京时间转换、ISO 输入、文本行对齐、行内差异和非法输入。
